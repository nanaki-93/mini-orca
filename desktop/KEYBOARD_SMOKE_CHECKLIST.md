# Desktop keyboard smoke checklist

Run this checklist with a Go project imported in Mini-Orca.

1. Press `Cmd/Ctrl+1` through `Cmd/Ctrl+4`; Summary, Analysis, Bugs, and Editor each become active. `Cmd/Ctrl+Tab` cycles through the same four destinations.
2. Press `Cmd/Ctrl+P` to choose an open file and `Cmd/Ctrl+Shift+O` to choose a symbol. Confirm the source remains selectable and read-only.
3. At less than 1000dp, confirm the compact file/symbol brief remains above source; use Files and Action drawers without losing the selected file.
4. In Bugs, use Tab to reach filters and finding actions. Press `Cmd/Ctrl+Shift+F` to return to Bugs.
5. In Editor, use `Cmd/Ctrl+K` to open the action route, select or create one target, Tab to the chat composer, and press `Cmd/Ctrl+Enter` to send.
6. Tab to the declaration and imports fields, edit only the draft, then press `Cmd/Ctrl+Shift+V` to validate and `Cmd/Ctrl+Shift+C` to run focused checks.
7. Confirm Apply names the selected file and symbol. Cancel its dialog with Escape; confirm Apply only after the fresh checks complete.
8. During an open dialog or active request, press Escape and confirm only that dialog/request closes or cancels. With no active dialog/request, Escape leaves the current workspace and source unchanged.
9. After Apply and Undo, confirm the selected source and brief refresh and that old draft/check evidence is gone.
