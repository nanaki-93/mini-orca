# Mini-Orca logo

The mark combines an orca's dorsal fin and eye patch with three curved paths
joining its body. The paths represent work converging under one orchestrator.
The upward angle and charcoal/green palette keep the design away from the blue
whale carrying containers and the nautical wheel motifs in the
[Docker](https://www.docker.com/company/newsroom/media-resources/) and
[Kubernetes](https://github.com/kubernetes/kubernetes/blob/master/logo/usage_guidelines.md)
identities.

These are standalone design assets; they are not installed in the desktop UI or
native application bundle.

| Asset | Use |
| --- | --- |
| [Primary mark](mini-orca-mark.svg) | Charcoal and forest green, transparent background; light surfaces |
| [Dark-surface mark](mini-orca-mark-dark.svg) | Ivory and sage, transparent background; dark surfaces |
| [Single-color mark](mini-orca-mark-mono.svg) | Inherits `currentColor` when inlined; black when opened standalone |
| [Horizontal lockup](mini-orca-lockup.svg) | Mark with editable Mini-Orca lettering |
| [App icon](mini-orca-app-icon.svg) | Rounded charcoal tile with transparent outer corners |
| [Preview](preview.png) | Light/dark presentation and small-size examples |

The matching PNG exports are raster copies of the SVG artwork, including actual
alpha transparency. The marks and app icon are exported at 1024 × 1024; the
horizontal lockup is 1480 × 512. The SVGs contain no external resources.

Use the mark at 24 px or larger where possible. Preserve the eye-patch opening,
the gaps between the paths and the original proportions. Leave at least one path
width of clear space around the visible silhouette. The horizontal lockup uses
live text with the app's system sans-serif stack; its lettering may vary with
installed fonts. Convert text to outlines in a vector editor before sending a
fixed wordmark to print.
