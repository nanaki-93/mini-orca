# Mini-Orca release notes

## v4.4.0 — Focused local desktop workflow

The current release supports scoped model profiles, project analysis, Security
rules and advisory review, source-based Performance review, and measured
benchmarks. The desktop provides file-bound declaration drafts, temporary checks,
explicit Review/Apply and guarded Undo. Source and composed diffs remain
read-only. See [README.md](README.md) for current usage, [CONFIG.md](CONFIG.md)
for setup and [docs/api-contract.md](docs/api-contract.md) for the API contract.
