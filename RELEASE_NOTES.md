# Mini-Orca release notes

## v4.4.0 — Focused local desktop workflow

The desktop uses Wails/React with scoped model profiles, unified analysis,
Security rules and advisory Performance review. Chat prepares checked proposals
across captured Go/Markdown files with explicit Apply and guarded grouped Undo.
The Kotlin client, declaration editing APIs, draft benchmarks and separate legacy
analysis jobs have been removed. See [workflow migration](docs/api-contract.md#retired-workflows),
[README.md](README.md) for current usage and [CONFIG.md](CONFIG.md) for setup.
