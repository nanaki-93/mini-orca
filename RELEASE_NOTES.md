# Mini-Orca release notes

## v4.4.0 — Focused local desktop workflow

Current capabilities include independent `analyze`, `bug` and `function` model
profiles, scoped provider confirmation, file-bound declaration drafts, temporary
checks, explicit Apply and guarded Undo. Source and composed diffs stay read-only.
The loopback API has one current contract; old browser routes and model fallback
configuration are removed.

Engineering insights and source-based Performance review are implemented. The
current UI uses Jewel and shared dark IDE components. Native, real-provider and
final distribution acceptance remains incomplete; see
[the acceptance record](docs/RELEASE_ACCEPTANCE.md).

The next [improvement plan](PLAN.md) covers clearer function workflows, cleanup,
Security and measured evidence. These planned features are not release claims.
Older release history is available in Git. Use [CONFIG.md](CONFIG.md) and the
[current API guide](docs/api-contract.md) for supported setup and contracts.
