# Mini-Orca API

The canonical human API guide is
[`docs/api-contract.md`](docs/api-contract.md). It is the one maintained route
inventory, lifecycle description, and safety contract for the loopback daemon.

Machine-readable request and response schemas are in
[`docs/openapi.yaml`](docs/openapi.yaml). The route characterization test keeps
both documents aligned with daemon registrations.
