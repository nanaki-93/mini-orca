Non-Negotiable Safety, Consent & Mutation Invariants

1. Zero Passive Side Effects

Opening, restoring, navigating, previewing, or reading history never contacts a model provider, never executes project code, and never modifies source files or Git refs.

2. Scope-Bound Consent & Trust

Every non-loopback HTTP or CLI (agy/pi) prompt request requires per-request confirm_remote_provider: true. Running go test or Git checkout/merge requires separate in-memory execution-trust for the exact project_revision.

3. Identity-Guarded Mutation & Undo

Source mutation requires a checked proposal (revision + hash), explicit diff Review (reviewed_hash), and explicit Apply. Grouped recovery journals verify pre-Apply and post-Apply SHA-256 hashes before Apply or Undo.

Deterministic Go AST Security Rules (go-rules-v1)

Implemented in internal/project/securityrules/security_rules.go. Evaluates Go ASTs with lexical scope tracking (tracking imports, dot imports, shadowed identifiers, and tls.Config variables/collections). Returns at most 5 source-order matches per file (evidence_kind: "rule_match").

go.tls.insecure-skip-verify CWE-295 · HIGH

Detects crypto/tls.Config composite literals or field assignments (including pointers, slices, arrays, and maps of tls.Config) that set InsecureSkipVerify to the predeclared boolean true.

go.shell.dynamic-command CWE-78 · HIGH

Detects os/exec.Command or CommandContext invocations of sh/bash/zsh/dash/ksh -c, cmd /c, or powershell/pwsh -Command|-c where the command argument is not a static string literal or concatenation of static literals.

Context Policy v2 & Instruction Hierarchy (internal/project)

Directory-Relative Ignore Semantics: Traverses .gitignore and .mini-orcaignore in every directory using ordered negation, **, and anchored paths. Hard exclusions always block .git/, .mini-orca/, .worktrees/, build/, node_modules/, symlinks, binary files, config.yaml, and secret-bearing files (.env*, keys/certs).

1 MiB Source Extraction Bound: Index Schema v3 streams SHA-256 hashes and line counts for all files, while AST/regex symbol extraction (internal/project/symbols across 35+ languages) is bounded to text files ≤ 1 MiB.

Root-to-Directory AGENTS.md Hierarchy: Applicable AGENTS.md guides are fingerprinted (instructions_fingerprint) and supplied to analysis, security reviews, explanations, feature generation, and 4-stage workflows. Editing an applicable AGENTS.md marks dependent cached AI reports stale.

Git Operations, Private-Index Commits & Worktree Isolation (internal/app/gitops)

1. Private-Index CAS Commit

Apply & Commit writes reviewed blobs into a temporary GIT_INDEX_FILE, runs git write-tree + git commit-tree, and updates the branch ref with compare-and-swap against the captured HEAD. Unrelated staged/untracked files are never swept into the commit; hooks and signing are bypassed.

2. Isolated .worktrees/ Routing

POST /api/projects/current/git/worktrees creates a branch & worktree inside .worktrees/ (added to .git/info/exclude). Any /api/projects/current/* route accepts ?worktree_path=/abs/path (cmd/daemon/worktree_router.go), routing to an isolated app.Service and project.Manager per checkout.

3. Merge & Finding Completion

POST /api/projects/current/git/merge verifies both checkouts are clean, merges the worktree source_head, marks all linked finding_targets whose fix commit is in the merged history as Done (finding-completions.json), and removes the clean worktree while keeping its branch.
