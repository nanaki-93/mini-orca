# Dark UI direction

The earlier dark Mini-Orca and Aurora mocks document visual explorations, not
a required palette, pane arrangement or navigation model. New designs may depart
from both. See the current
[UI guidelines](../../desktop/UI_DESIGN_GUIDELINES.md) for interaction safety,
accessibility and verification expectations.

The current client uses a dark theme and Jewel. Mock sample tabs, terminal,
profile, scores and multi-file extraction are not evidence of supported features.
Native window controls and explicit Review before Apply remain current product
behavior; changing the look must not silently bypass the guarded edit workflow.

The old dark plan/baseline/contrast/acceptance documents were consolidated here and
in [release acceptance](../RELEASE_ACCEPTANCE.md). UI-04 closes the attainable Task
149 native checks; REL-01 retains the explicit release limitations.
Current measured token pairs remain in [UI_CONTRAST.md](../../desktop/UI_CONTRAST.md).
Full historical instructions and old measurements are recoverable from Git.
