# Go TUI convergence plan

Consolidate Mini-Orca on a pure Go Terminal UI (`cmd/tui` and `internal/tui`) backed by the existing loopback Go daemon (`cmd/daemon`, `internal/app`, `internal/api`, `internal/project`). Remove the Wails/React desktop client (`desktop/`), Node/npm build steps and Playwright browser harness while preserving source identity checks, explicit Apply, guarded Undo, provider consent and actionable errors. The read-only browser dashboard is out of scope for this migration while keeping `internal/api` intact.

Each implementation step is verified and committed separately. This plan covers the current request; older task lists do not authorize work.

Port TUI domain helpers and guarded daemon client to Go (`internal/tui`).** Create typed wire/domain models (`models.go`), the route-guarded HTTP client with request cancellation and tombstones (`client.go`), and pure Go domain logic (`domain.go`) for diff hunk splitting/rejection, finding deduplication and severity sorting, 4-stage Agent Studio item derivation, `AGENTS.md` lesson graduation/bootstrap checks and structured architecture handbook/ASCII diagram synthesis. Verify with `go test -race ./internal/tui/...` and `go vet ./internal/tui/...`.
